# NEXVARY Lingo
تعلّم اللغة بالممارسة: مواقف متكيّفة، استرجاع نشط، مراجعة متباعدة، واختبارات انتقال إلى مواقف جديدة.

## الحالة الفعلية
مرحلة تصور المنتج والبحث والتخطيط. لا يوجد تطبيق أو APK منشور حتى الآن.
المواصفات قرارات أولية قابلة للمراجعة، ولا تمثل إثباتًا لتفوق تعليمي.

## وثيقة التنفيذ
[تصور المنتج، البحث، الواجهة، البنية، المخاطر ومراحل التنفيذ](docs/PRODUCT-PLAN-AR.md)

## النطاق الأولي المقترح
Android، واجهة عربية وإنجليزية، تعليم الإنجليزية للبالغين الناطقين بالعربية.
مسارات الحياة اليومية والسفر والعمل. يبدأ الاستخدام محليًا دون اشتراط إنشاء حساب.

## مبادئ المشروع
- صحة التعلم وسهولة الاستخدام قبل عدد المميزات.
- العربية RTL ولغة التعلم باتجاهها الصحيح.
- لا مفاتيح خدمات أو ملفات توقيع في المستودع.
- لا تقييم نطق من النص وحده ولا شهادات مستوى غير متحقق منها.
- كل مرحلة لها دليل قبول، ولا يُعلن نجاح بناء أو اختبار لم ينفذ.

## الخطوة التالية
تثبيت مصفوفة أدوات البناء، ثم إنشاء نواة صغيرة وتشغيل اختبارات المحرك وبناء Android في CI.
